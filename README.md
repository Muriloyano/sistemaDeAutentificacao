#  Sistema de Autenticação 

Um sistema completo de autenticação de usuários, englobando desde a interface visual responsiva até a lógica de negócios e segurança no servidor. 

##  Sobre o Projeto
Este projeto foi desenvolvido para demonstrar a integração entre um front-end fluido (Dark Mode) e uma API robusta. O sistema conta com fluxos completos de Cadastro, Login, Recuperação de Senha e Dashboard (Home).

##  Tecnologias Utilizadas
- **Front-end:** HTML, CSS (Variáveis CSS, Flexbox) e JavaScript .
- **Back-end:** C# e .NET (Criação de API, envio automático de e-mails de recuperação).

## Funcionalidades
- Layout de dupla coluna com efeitos interativos (Mouse tracking 3D).
- Validação de formulários no front-end.
- Padronização de design system utilizando variáveis CSS (`:root`).
- Integração de e-mail via back-end (C#) para o fluxo de "Esqueci minha senha".

##  Acesso ao Projeto
Você pode visualizar todo o código-fonte e a estrutura do projeto acessando o repositório:
https://github.com/Muriloyano/sistemaDeAutentificacao

### Como rodar localmente
1. Clone este repositório.
2. Abra a pasta `frontend` no VS Code ou no seu navegador para visualizar as telas.
3. Abra a pasta `backend` na sua IDE e rode a aplicação C# para ativar a API e o envio de e-mails.
